# EasyGoal — LLM Pages & Navigation Guide

> Instrui qualquer IA sobre onde adicionar links de documentação e navegação
> em cada página dos projetos reais do ecossistema Easy Goal.
>
> Leia junto com `llms.txt` para contexto completo.

---

## Variável de Ambiente — URL da Documentação

Adicionar ao `.env.example` e `.env.local` de **todos os projetos**:

```env
NEXT_PUBLIC_DOCS_URL=https://docs.easygoal.com.br
```

Em desenvolvimento: `NEXT_PUBLIC_DOCS_URL=http://localhost:3002`

Usar sempre via `process.env.NEXT_PUBLIC_DOCS_URL` — nunca hardcoded.

---

## Padrão de Link de Documentação

```tsx
// Links de docs abrem sempre em nova aba
const docsUrl = process.env.NEXT_PUBLIC_DOCS_URL ?? 'https://docs.easygoal.com.br';

<a
  href={`${docsUrl}/sso/visao-geral`}
  target="_blank"
  rel="noopener noreferrer"
  className="text-sm text-muted-foreground hover:text-primary underline"
>
  Ver documentação
</a>
```

## PROJETO: app-front (localhost:3001)

### Onde adicionar (por prioridade)

#### 1. Sidebar — link permanente para Documentação
**Arquivo:** `src/components/layout/Sidebar.tsx`
**Onde:** Na seção inferior, após o link "Configuracoes" e antes do `<UserMenu>`
**Ícone:** `BookOpen` de `lucide-react`

```tsx
// Adicionar após o bloco de "Configuracoes":
<Link
  href={`${process.env.NEXT_PUBLIC_DOCS_URL ?? 'https://docs.easygoal.com.br'}`}
  target="_blank"
  rel="noopener noreferrer"
  className={cn(
    "group flex items-center rounded-lg px-3 py-2.5 text-sm font-medium transition-all duration-200",
    isCollapsed ? "justify-center" : "gap-3",
    "text-sidebar-foreground hover:bg-sidebar-accent/50 hover:text-sidebar-accent-foreground"
  )}
  title={isCollapsed ? "Documentação" : undefined}
>
  <BookOpen className="h-5 w-5 text-sidebar-foreground group-hover:text-sidebar-accent-foreground" />
  {!isCollapsed && "Documentação"}
</Link>
```

#### 2. UserMenu dropdown — link de Documentação
**Arquivo:** `src/components/layout/UserMenu.tsx`
**Onde:** No `<div className="py-1">`, após as opções de email/senha e antes do separador de logout
**Ícone:** `BookOpen` de `lucide-react`

```tsx
// Adicionar no bloco de opções do dropdown:
<a
  href={process.env.NEXT_PUBLIC_DOCS_URL ?? 'https://docs.easygoal.com.br'}
  target="_blank"
  rel="noopener noreferrer"
  className="flex items-center gap-3 rounded-md px-3 py-2 text-sm text-sidebar-foreground transition-colors hover:bg-sidebar-accent hover:text-sidebar-accent-foreground"
  onClick={() => setIsOpen(false)}
>
  <BookOpen className="h-4 w-4" />
  Documentação
</a>
```

## PROJETO: SSO (localhost:3000)

### Onde adicionar links de documentação

#### 1. Página de Login `/auth/login`
**Arquivo:** `src/app/auth/login/page.tsx`
**Onde:** Rodapé do `<CardContent>`, após o link "Criar conta"

```tsx
<div className="text-center text-xs text-muted-foreground pt-2">
  <a
    href={`${process.env.NEXT_PUBLIC_DOCS_URL ?? 'https://docs.easygoal.com.br'}/sso/fluxo-oauth`}
    target="_blank"
    rel="noopener noreferrer"
    className="hover:text-primary underline"
  >
    Documentação
  </a>
</div>
```

#### 2. Header do SSO
**Arquivo:** `src/components/Header/index.tsx`
**Onde:** Link "Documentação" no header

#### 3. Dashboard do SSO `/dashboard`
**Arquivo:** `src/app/dashboard/page.tsx`
**Onde:** Adicionar botão "Ir para o Easy Goal" no `<div className="flex gap-4 pt-4">`

```tsx
// Junto ao botão "Sair" no dashboard do SSO:
<a
  href={process.env.NEXT_PUBLIC_APP_FRONT_URL ?? 'https://app.easygoal.com.br'}
  className="..."
>
  Ir para o Easy Goal
</a>
```

> **Importante:** O `NEXT_PUBLIC_APP_URL` do SSO aponta para o próprio SSO.
> Criar `NEXT_PUBLIC_APP_FRONT_URL=http://localhost:3001` para linkar ao app-front.

### Regras obrigatórias
- `target="_blank"` + `rel="noopener noreferrer"` em todos os links externos
- Nunca hardcode URL — sempre `process.env.NEXT_PUBLIC_DOCS_URL`
- Não alterar lógica de autenticação, apenas UI/navegação
