## O que é o Club LP?

O **Club LP** é uma landing page de exemplo. Ela serve como referência de implementação para qualquer produto que precise:

1. Autenticar usuários via SSO EasyGoal usando `@easygoal/packages/auth`
2. Exibir um banner com dados do usuário logado (nome, se é produtor)
3. Linkar de volta para o app principal (dashboard ou painel do produtor)

> **Stack:** Next.js 14+ (App Router) — mesmo padrão do app-front. Não tem página de perfil dedicada: os dados do usuário aparecem em um banner na própria landing page.

## Arquitetura do Fluxo

```
[Club LP]  →  [SSO]  →  [Club LP callback]  →  [Banner na landing page]
   (1)          (2)              (3)                     (4)

1. Botão "Entrar" (via useSSOLogin) redireciona para SSO com redirect_to
2. SSO autentica (login com conta EasyGoal) e redireciona de volta
3. Callback recebe ?eg_session=<token>, salva em cookie httpOnly (7 dias)
4. EgSessionProvider lê a sessão via /api/auth/session e alimenta useEgSession()
```

Não há `access_token`/`refresh_token`/`state` nesse fluxo — o parâmetro é um único `eg_session` (mesmo padrão descrito em [Fluxo OAuth](/sso/fluxo-oauth)).

## Estrutura da implementação

Login e logout são disparados **client-side** pelos hooks do package (`useSSOLogin`, `handleSignout`) — não existem rotas `/auth/login` nem `/auth/logout` no próprio Club LP. A landing page usa um provider de sessão, uma rota de callback, um endpoint que decodifica os claims e componentes de UI (banner e botão de login) que consomem esses hooks. Veja o passo a passo completo em [Implementação](/club-lp/implementacao).

## Variáveis de Ambiente

```env
# .env.local do projeto Club
NEXT_PUBLIC_SSO_URL=https://sso.easygoal.com.br
NEXT_PUBLIC_EASYGOAL_APP_URL=https://app.easygoal.com.br

# API key do produto registrado no SSO (permite silent auth cross-domain)
NEXT_PUBLIC_EASY_API_KEY=eg_sandbox_sua_chave_aqui
```
