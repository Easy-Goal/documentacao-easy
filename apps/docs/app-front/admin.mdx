## Visão geral

A área admin é acessada por usuários com `is_super_admin: true`. O sidebar exibe quatro seções de gestão:

| Seção | Rotas | Finalidade |
|-------|-------|------------|
| **Gestão** | `/admin/users`, `/admin/companies`, `/admin/producers` | Pessoas e organizações |
| **Produtos** | `/admin/saas-products`, `/admin/saas-steps`, `/admin/services` | Catálogo e aprovações |
| **Financeiro** | `/admin/affiliates`, `/admin/withdrawals`, `/admin/service-requests`, `/admin/api-apps`, `/admin/reports` | Financeiro e relatórios |
| **Comunidade** | `/admin/beta`, `/admin/discord/events` | Programa beta e Discord |
| **Sistema** | `/admin/system` | Configurações, admins e logs |

<Warning>
  O perfil Admin não tem acesso às áreas de Usuário ou Produtor. Isso é intencional para manter a separação entre a visão de gestão e a visão de cliente.
</Warning>

## Dashboard Admin

**Rota:** `/admin/dashboard`

Visão geral da plataforma em números:

- Total de usuários e empresas cadastradas
- Novos produtores aguardando verificação
- Produtos pendentes de aprovação
- Saques de afiliados a processar
- Receita consolidada

---

## Gestão de usuários

**Rota:** `/admin/users`

Lista completa de todos os usuários cadastrados na plataforma. Permite:

- Buscar por nome, e-mail ou empresa
- Filtrar por perfil (admin, produtor, usuário)
- Ver detalhes do perfil e empresa vinculada
- Alterar role_id do usuário (permissões customizadas)

---

## Gestão de empresas

**Rota:** `/admin/companies`

Visualize e gerencie as empresas cadastradas. Cada usuário é vinculado a uma empresa no momento de completar o perfil no SSO.

Informações exibidas:
- Razão social e CNPJ
- Plano contratado
- Usuários vinculados
- Status da empresa

---

## Gestão de produtores

**Rotas:** `/admin/producers` · `/admin/producers/new`

Controle completo dos parceiros produtores:

### Cadastrar novo produtor

Em `/admin/producers/new`, preencha:
- Dados do usuário a ser cadastrado como produtor
- Empresa associada
- Informações de contato e contrato

### Gerenciar produtores existentes

- Aprovar (`verified`), suspender (`suspended`) ou rejeitar (`rejected`) produtores
- Visualizar produtos publicados por cada produtor
- Consultar métricas de performance

## Produtos SaaS

**Rotas:** `/admin/saas-products` · `/admin/saas-products/pending` · `/admin/saas-products/[id]`

Central de aprovação de produtos SaaS submetidos por produtores.

### Fluxo de aprovação

<Steps>
  <Step title="Produtor submete produto">
    O produtor conclui os 7 steps e solicita publicação. O produto aparece em `/admin/saas-products/pending`.
  </Step>
  <Step title="Revisão pelo admin">
    O admin acessa `/admin/saas-products/[id]` e analisa cada step: dados básicos, SSO, pagamentos, compliance, etc.
  </Step>
  <Step title="Aprovação ou rejeição">
    - **Aprovado:** produto publicado em `/saas` para todos os usuários
    - **Rejeitado:** feedback enviado ao produtor com os pontos a corrigir
  </Step>
</Steps>

### Filtros de status

| Rota | Status exibido |
|------|---------------|
| `/admin/saas-products/pending` | Aguardando revisão |
| `/admin/saas-products/approved` | Publicados no catálogo |
| `/admin/saas-products/rejected` | Reprovados |

## Steps Padrão

**Rota:** `/admin/saas-steps`

Gerencie os templates de steps que compõem o processo de onboarding de produtos SaaS. Cada step tem:

- Nome e descrição
- Tipo (formulário, integração técnica, validação manual)
- Ordem no fluxo
- Se é obrigatório ou opcional

Alterações nos steps padrão afetam o processo de todos os novos produtos criados a partir dessa data.

## Saques de Parceiros

**Rota:** `/admin/withdrawals`

Processe os pedidos de saque de comissões dos afiliados:

<Steps>
  <Step title="Afiliado solicita saque">
    O afiliado configura a chave PIX em `/affiliate/settings` e solicita o saque das comissões aprovadas.
  </Step>
  <Step title="Admin revisa">
    Em `/admin/withdrawals`, o admin vê todos os pedidos pendentes com valor e dados PIX.
  </Step>
  <Step title="Processamento">
    O admin confirma o pagamento via PIX e marca o saque como processado. O status das comissões é atualizado para `paid`.
  </Step>
</Steps>

## API Apps

**Rota:** `/admin/api-apps`

Gerencie aplicativos de terceiros que solicitam integração via API com a plataforma. Cada `api-app` representa uma aplicação externa que:

- Solicita acesso à API da Easy Goal
- Precisa de aprovação antes de operar
- Gera um client_id/secret para autenticação

## Relatórios

**Rota:** `/admin/reports`

Relatórios consolidados da plataforma:

- **Receita:** MRR total, crescimento mensal, breakdown por produto
- **Usuários:** novos cadastros, churn, retenção
- **Produtores:** performance comparativa entre produtores
- **Afiliados:** volume de comissões geradas e pagas

## Discord — Eventos

**Rota:** `/admin/discord/events`

Sincronize e gerencie os eventos do servidor Discord da Easy Goal dentro do painel admin:

- **Sincronizar eventos:** importa eventos criados no Discord para o painel (via bot)
- **Aprovar / reprovar:** cada evento pode ser aprovado ou rejeitado para aparecer no catálogo da plataforma
- **Configurações por evento:** rank mínimo exigido, planos habilitados, produto associado, destaque
- **Link externo:** acesso direto ao evento no Discord

Eventos aprovados ficam visíveis para usuários que atendam ao rank e plano configurados.

## Sistema

**Rotas:** `/admin/system/settings` · `/admin/system/admins` · `/admin/system/logs`

### Configurações do Sistema

Parâmetros globais da plataforma (taxas padrão de comissão de afiliados, prazos de aprovação, etc.)

### Administradores

Gerencie os usuários com perfil `is_super_admin: true`. Adicione ou remova administradores com cuidado — este perfil tem acesso irrestrito ao sistema.

### Logs

Registro de atividades administrativas para auditoria:

- Ações de aprovação/rejeição de produtos
- Alterações de perfil de usuário
- Processamento de saques
- Configurações do sistema alteradas
