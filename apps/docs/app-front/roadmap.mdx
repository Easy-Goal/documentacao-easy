## O que é o Roadmap Público

O roadmap público é onde você acompanha o que está sendo desenvolvido no Easy Goal, vota nas features que mais importam para você e sugere novas funcionalidades.

É uma forma direta de influenciar o produto — as features com mais votos sobem na prioridade de desenvolvimento.

## Votando em features

Para votar em uma feature que já está no roadmap:

1. Acesse a seção **Roadmap** no menu lateral
2. Navegue pelas colunas: **Planejado**, **Em Desenvolvimento** e **Lançado**
3. Clique no botão de voto na feature desejada
4. Seu voto é registrado e somado ao total

<Note>
Cada usuário pode votar em múltiplas features, mas apenas uma vez por feature.
</Note>

## Sugerindo novas features

Tem uma ideia que não está no roadmap?

1. Acesse a seção **Roadmap**
2. Clique em **Sugerir Feature**
3. Descreva a funcionalidade — quanto mais detalhado, melhor
4. Sua sugestão entra na triagem da equipe

Sugestões aprovadas entram no roadmap e você recebe uma notificação quando o status muda.

## Status das features

| Status | O que significa |
|--------|----------------|
| **Planejado** | Feature aprovada, ainda não iniciada |
| **Em Desenvolvimento** | Trabalho em andamento |
| **Lançado** | Disponível na plataforma |

## Notificações de status

Quando o status de uma feature que você votou ou sugeriu muda, você recebe uma notificação in-app. As notificações aparecem no sino no canto superior direito da plataforma.

Você pode gerenciar suas preferências de notificação em **Configurações → Notificações**.
