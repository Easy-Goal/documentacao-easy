## Visão geral

Builders têm o perfil **Produtor** no app e acessam uma área dedicada aos próprios produtos. Um produto liberado entra na curadoria e pode virar parte da entrega de um cliente.

O sidebar do produtor exibe apenas **Meus SaaS**, apontando para `/producer/apps`:

| Seção | Rotas | Descrição |
|-------|-------|-----------|
| **Meus SaaS** | `/producer/apps` | Produtos publicados e em rascunho — único item de produtor no sidebar |

<Note>
`/producer/dashboard`, `/producer/reports`, `/producer/withdrawals` e `/producer/api-keys` são páginas reais, mas hoje **não aparecem no sidebar** — são acessadas por links diretos (ex: cards do dashboard geral) ou pela URL.
</Note>

## Dashboard do Produtor

**Rota:** `/producer/dashboard`

Visão consolidada da operação do produtor:

- Total de assinantes ativos por produto
- Receita mensal recorrente (MRR)
- Novas assinaturas e cancelamentos recentes
- Status dos produtos (aprovado, pendente, rejeitado)

## Meus SaaS

**Rotas:** `/producer/apps` · `/producer/apps/new` · `/producer/apps/[slug]`

Central de gestão de produtos SaaS. Da listagem, o produtor pode:

- Ver todos os produtos com seus status de publicação
- Criar um novo produto
- Editar um produto existente

### Criar novo produto

Ao acessar `/producer/apps/new`, o produtor preenche um formulário único (não um wizard multi-step):

<Steps>
  <Step title="Informações básicas">Nome, slug, descrição e categoria do SaaS.</Step>
  <Step title="Autenticação">Como os usuários fazem login: EasyGoal gerencia tudo, autenticação própria complementada pelo SSO, ou só SSO EasyGoal (sem distribuição).</Step>
  <Step title="Cobrança / Gateway">Escolha o gateway inicial: AbacatePay, Kiwify (informando o ID do produto e o papel da EasyGoal — co-produtor ou produtor principal) ou outro gateway via webhook manual.</Step>
</Steps>

Planos e API key são configurados **depois**, já dentro do produto criado (`/producer/apps/[slug]`), que expõe as abas **Produto**, **Planos**, **Co-produtores**, **Feedback**, **Integração** e **Analytics**.

## Relatórios

**Rota:** `/producer/reports`

Dashboard analítico com três abas de dados:

| Aba | Conteúdo |
|-----|----------|
| **Financeiro** | Receita total, comissão, saques pendentes e breakdown por produto |
| **Aquisição** | Funil GA4 (view → checkout → purchase), canais de tráfego, UTM interno, filtro por produto e período |
| **Assinantes** | Evolução de assinantes ativos, churn e MRR *(em breve)* |

Os dados de aquisição são alimentados pelo Google Analytics 4 provisionado automaticamente ao produto ser aprovado.

<Info>
  Para ver dados de aquisição, o produto precisa estar **aprovado**. GA4 + GTM são criados automaticamente nesse momento — nenhuma configuração manual é necessária.
</Info>

## Chaves de API

**Rota:** `/producer/api-keys`

Gerencie as credenciais para integrar seus sistemas com a plataforma Easy Goal via webhooks.

### Criando uma API Key

Cada chave de API é associada a um produto específico e permite que o sistema externo do produtor receba notificações de eventos via webhook.

```bash
# Exemplo de header de autenticação para APIs do produtor
Authorization: Bearer <api-key>
```

### Eventos suportados

| Evento | Descrição |
|--------|-----------|
| `purchase.completed` | Nova assinatura ou compra avulsa realizada |
| `subscription.cancelled` | Assinatura cancelada pelo cliente |
| `subscription.renewed` | Renovação de assinatura |

<Warning>
  Guarde sua API Key com segurança. Em caso de vazamento, revogue-a imediatamente e gere uma nova — não é possível recuperar uma chave revogada.
</Warning>

## Co-produtores

Cada produto tem uma aba **Co-produtores** (chamada "Squad" apenas do lado admin) onde o owner adiciona co-produtores que recebem split automático em cada pagamento.
