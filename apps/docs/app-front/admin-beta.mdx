## Visão geral

**Rota:** `/admin/beta`

O painel beta é exclusivo para `super_admin`. Permite gerenciar todos os usuários inscritos no programa de acesso antecipado da plataforma.

---

## Cards de resumo

No topo da página, três cards exibem os números consolidados do programa:

| Card | Descrição |
|------|-----------|
| **Total de betas** | Usuários que aceitaram o NDA e estão ativos |
| **Discord conectado** | Betas que vincularam a conta do Discord |
| **Cargo concedido** | Betas que já receberam o cargo no servidor |

---

## Tabela de usuários beta

Lista completa dos usuários inscritos no programa com as seguintes colunas:

| Coluna | Descrição |
|--------|-----------|
| **Nome** | Nome completo do usuário |
| **Email** | E-mail cadastrado na plataforma |
| **Aceito em** | Data de aceite do NDA |
| **Discord** | Username do Discord (se vinculado) |
| **Cargo** | Se o cargo no servidor já foi concedido |
| **NDA** | Versão do termo aceito |

---

## Ações disponíveis

### Convidar usuário beta

Clique em **"Convidar Beta"** para enviar um convite por e-mail a um novo usuário. O e-mail inclui o link de aceite com o NDA.

### Conceder cargo no Discord

Para usuários que já vincularam o Discord mas ainda não receberam o cargo:

1. Localize o usuário na tabela
2. Clique em **"Conceder cargo"**
3. O bot do Discord atribui o cargo `Beta Member` automaticamente no servidor Easy Club

<Info>
  O cargo só pode ser concedido para usuários com Discord vinculado. Usuários sem integração Discord ativa aparecem sem essa opção.
</Info>

### Exportar CSV

Clique em **"Exportar CSV"** para baixar a lista completa de beta users com todos os campos — útil para relatórios e comunicações em massa.

## Fluxo completo de um beta user

<Steps>
  <Step title="Convite enviado pelo admin">
    Admin cria o convite em `/admin/beta`. O usuário recebe e-mail com link de acesso.
  </Step>
  <Step title="Usuário cria conta e aceita NDA">
    Cadastro feito em app.easygoal.com.br. NDA aceito durante o onboarding.
  </Step>
  <Step title="Usuário vincula Discord">
    Em **Configurações → Conta → Conectar Discord**. O `discord_id` e `discord_username` são registrados.
  </Step>
  <Step title="Admin concede cargo">
    Admin aciona o botão na tabela. O bot chama `/api/admin/discord/grant-role` e o cargo é aplicado no servidor.
  </Step>
</Steps>
