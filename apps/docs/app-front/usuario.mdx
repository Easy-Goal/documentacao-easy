## Visão geral

No app, o cliente acompanha o que a Easy Goal vai entregar e vê as faturas. Quem precisa de um resultado não precisa navegar por catálogo nem escolher ferramenta sozinho.

| Seção | Rota | Descrição |
|-------|------|-----------|
| **Dashboard** | `/dashboard` | Ferramentas ativas, entregáveis e faturas pendentes |
| **Entregáveis** | `/services` | O que a Easy Goal vai entregar e em que etapa cada item está |
| **Faturas** | `/billing` | Histórico dos entregáveis e das ferramentas |
| **Configurações** | `/settings` | Perfil, e-mail, senha e empresa |

---

## Dashboard

**Rota:** `/dashboard`

Mostra três números: ferramentas ativas, entregáveis e faturas pendentes. Cada um leva à tela correspondente.

---

## Entregáveis

**Rota:** `/services`

Cada entregável aparece com a etapa atual. Os ativos ficam no topo e os concluídos ou cancelados, no histórico.

| Etapa | O que significa |
|-------|-----------------|
| Coletando dados | A Easy Goal precisa de informações suas |
| Aguardando orçamento | A proposta está sendo preparada |
| Aguardando assinatura | O contrato está pronto para você assinar |
| Aguardando pagamento | O link de pagamento foi gerado |
| Em andamento | A Easy Goal está executando |
| Concluído | Entregue |
| Cancelado | Não será executado |

---

## Faturas

**Rota:** `/billing`

A tela tem duas abas.

### Entregáveis

Lista os entregáveis com a situação de cada um. Quando há contrato ou pagamento pendente, o botão correspondente aparece no item. Se a Easy Goal pedir mais informações, o item mostra o aviso **Informação solicitada** e o botão **Responder**.

### Ferramentas

Lista as assinaturas das ferramentas contratadas para os seus entregáveis, com valor, frequência, data de contratação e próxima cobrança.

| Status | Descrição |
|--------|-----------|
| `pending` | Aguardando pagamento |
| `active` | Ativa |
| `suspended` | Suspensa por inadimplência, com botão para pagar a fatura e reativar |
| `cancelled` | Cancelada |
| `expired` | Expirada |
| `failed` | Pagamento não concluído |

**Cancelar:** disponível para assinaturas `active` ou `pending`. Um modal pede o motivo do cancelamento.

## Configurações da conta

**Rotas:** `/settings` · `/settings/email` · `/settings/password`

- **`/settings/email`:** alterar e-mail, para contas criadas com e-mail e senha.
- **`/settings/password`:** alterar senha, para contas criadas com e-mail e senha.

<Tip>
  Quem entra com Google, GitHub ou Microsoft altera a senha diretamente no provedor.
</Tip>
