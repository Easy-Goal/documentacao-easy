## Visão geral

A página de checkout é o ponto de conversão do seu produto. Acesse **Produtos → [Produto] → aba "Checkout"** para personalizar todos os elementos visuais e de persuasão.

<Note>
  O checkout só fica visível para compradores após o produto ser **aprovado** pela equipe Easy Goal.
</Note>

---

## Elementos personalizáveis

### Logo

Faça upload do logo do seu produto (recomendado: PNG com fundo transparente, 200×60px). Aparece no topo da página de checkout.

### Cover (imagem de capa)

Imagem de destaque exibida ao lado do formulário de pagamento (recomendado: 1200×630px). Use para transmitir visualmente o valor do produto.

### Benefícios

Lista de até 6 itens exibida no checkout para reforçar o valor da oferta:

```
✓ Benefício 1
✓ Benefício 2
✓ Benefício 3
```

Cada item aceita até 80 caracteres. Seja direto e orientado a resultado.

### Garantia

Texto curto de garantia exibido abaixo do botão de compra (ex: "Satisfação garantida ou seu dinheiro de volta em 7 dias"). Aumenta a confiança do comprador.

### Urgência

Elemento opcional de escassez/urgência:

| Tipo | Descrição |
|------|-----------|
| **Contador de tempo** | Cronômetro regressivo até encerramento da oferta |
| **Vagas limitadas** | Exibe quantidade de vagas restantes |
| **Desativado** | Sem elemento de urgência |

---

## Link de afiliado no checkout

Produtores com o programa de afiliados ativo podem visualizar o link de afiliado padrão do produto na aba Checkout. Esse link é gerado automaticamente e rastreia conversões via `?ref=` na URL.

Para compartilhar com afiliados específicos, acesse **Relatórios → Afiliados** e copie o link personalizado de cada afiliado.

## Boas práticas

<CardGroup cols={2}>
  <Card title="Cover direto ao ponto" icon="image">

  </Card>
  <Card title="Benefícios orientados a resultado" icon="list-check">
    "Economize 3h por semana" converte mais que "Ferramenta de automação".
  </Card>
  <Card title="Garantia explícita" icon="shield-check">
    Nomear os dias de garantia (7, 14 ou 30) reduz objeções de compra.
  </Card>
  <Card title="Urgência real" icon="clock">
    Use urgência somente se for verdadeira — limites fictícios prejudicam a reputação do produto.
  </Card>
</CardGroup>
