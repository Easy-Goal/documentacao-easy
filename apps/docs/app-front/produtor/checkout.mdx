## Visão geral

Não existe uma aba "Checkout" na Área do Produtor. A configuração do checkout é feita em um **modal** — "Configurar checkout" — aberto a partir da aba **Planos** de cada produto (`/producer/apps/[slug]?tab=plans`).

<Note>
  O checkout só fica visível para compradores após o produto ser **aprovado** pela equipe Easy Goal.
</Note>

---

## Configuração de pagamento

No topo do modal, uma **matriz de gateways por método de pagamento** liga/desliga cada método (PIX, boleto, cartão) e escolhe qual gateway o processa — AbacatePay, Mercado Pago ou Kiwify, dependendo do que estiver disponível para o produto. Essa escolha vale para qualquer plano do produto, avulso ou recorrente.

Se o produto tem co-produtores ativos, o modal também mostra a distribuição por venda (percentual de cada co-produtor + percentual líquido do produtor).

---

## Elementos personalizáveis

O bloco **Configuração do Checkout** do modal tem os seguintes toggles:

| Elemento | Descrição |
|---|---|
| Logo do produto | Exibe a imagem de logo no resumo do pedido |
| Imagem de capa | Exibe o banner 16:9 no topo do card de checkout |
| Descrição | Exibe a descrição do produto abaixo do nome |
| Vídeo / VSL | Exibe o vídeo de apresentação (YouTube/Vimeo) |
| Selo de garantia | Exibe "Garantia de X dias"; o número de dias é configurável |
| Contador de urgência | Contador **decorativo** — não existe opção de "vagas limitadas" |
| Seção de benefícios | Lista livre de benefícios (sem limite fixo de itens ou caracteres na UI) |

### Link de Checkout Direto

Quando o produto está aprovado e tem um plano configurado, o modal gera um link de checkout direto (`/checkout?product_id=...`), com uma URL de redirecionamento pós-compra opcional. Esse link leva direto ao checkout.

### URL de Checkout Externo

Aparece apenas quando o produtor gerencia o próprio gateway: um campo para informar a URL do checkout externo (ex: `https://pay.kiwify.com.br/seu-produto`).

## Boas práticas

<CardGroup cols={2}>
  <Card title="Cover direto ao ponto" icon="image">
    Use uma imagem que mostre o produto em uso ou o resultado esperado. Evite banners genéricos.
  </Card>
  <Card title="Benefícios orientados a resultado" icon="list-check">
    "Economize 3h por semana" converte mais que "Ferramenta de automação".
  </Card>
  <Card title="Garantia explícita" icon="shield-check">
    Nomear os dias de garantia (7, 14 ou 30) reduz objeções de compra.
  </Card>
  <Card title="Urgência real" icon="clock">
    Use urgência somente se for verdadeira — limites fictícios prejudicam a reputação do produto.
  </Card>
</CardGroup>
