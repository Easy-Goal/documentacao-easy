## Visão geral

**Rota:** `/producer/reports`

A seção de Relatórios consolida os dados financeiros e de aquisição de todos os seus produtos SaaS em três abas.

---

## Aba Financeiro

Visão financeira consolidada da operação:

| Métrica | Descrição |
|---------|-----------|
| **Receita total** | Soma de todos os pagamentos confirmados no período |
| **Comissão Easy Goal** | 20% retidos pela plataforma |
| **Receita líquida** | Valor disponível para saque (após comissão e co-produtores) |
| **Saques pendentes** | Valor solicitado ainda não processado |
| **Breakdown por produto** | Receita individual de cada produto no período |

Filtros disponíveis: **período** (últimos 7d, 30d, 90d, customizado) e **produto**.

---

## Aba Aquisição

Dados do funil de conversão alimentados pelo Google Analytics 4 provisionado automaticamente para cada produto aprovado.

### Funil de conversão

```
Visualizações da página do produto
         ↓
    Início de checkout
         ↓
     Compra realizada
```

| Evento GA4 | Quando é disparado |
|------------|-------------------|
| `view_product` | Usuário acessa a página do produto no marketplace |
| `start_checkout` | Usuário inicia o processo de checkout |
| `purchase` | Pagamento confirmado |

### Canais de aquisição

Origem do tráfego classificada por canal:

- **Orgânico** — busca direta, SEO
- **Afiliado** — tráfego via link de afiliado rastreado
- **UTM** — campanhas com parâmetros UTM customizados
- **Direto** — acesso sem referência

### Filtros disponíveis

- Produto (individual ou consolidado)
- Período
- Canal de aquisição

<Info>
  Os dados de aquisição aparecem somente após o produto ser **aprovado** pela equipe. GA4 e GTM são provisionados automaticamente nesse momento — nenhuma configuração manual é necessária.
</Info>

## Perguntas frequentes

<AccordionGroup>
  <Accordion title="Os dados de aquisição são em tempo real?">
    Não. O GA4 processa dados com latência de até 24-48h. Para eventos recentes, pode haver defasagem na exibição.
  </Accordion>

  <Accordion title="Posso ver os dados de todos os meus produtos ao mesmo tempo?">
    Sim. Por padrão, a aba Aquisição consolida todos os produtos. Use o filtro de produto para ver individualmente.
  </Accordion>

  <Accordion title="O que acontece com o saldo antes de solicitar saque?">
    O saldo fica disponível para saque 3 dias após o próximo vencimento da assinatura. Isso garante uma margem de segurança contra chargebacks. Consulte [Equipe & Co-produção](/app-front/produtor/squad) para detalhes sobre o fluxo de saques.
  </Accordion>
</AccordionGroup>
