## POST /webhooks/:gateway/:api_key

Recebe o webhook do gateway **do builder**. A Easy Goal só lê: não chama o gateway de volta e não guarda a chave secreta dele.

**URL:** `https://api.easygoal.com.br/webhooks/{gateway}/{api_key}`

<ParamField path="gateway" type="string" required>
  `abacatepay`. A Kiwify segue em `/webhooks/kiwify/{api_key}` até migrar. Gateway sem adaptador responde `404`.
</ParamField>

<ParamField path="api_key" type="string" required>
  Chave de API do produto. Chave inválida ou revogada responde `401`.
</ParamField>

### Verificação

| Situação | Resposta | Grava? | Libera acesso? |
|---|---|---|---|
| Segredo e assinatura corretos | `200` | Sim, `verified` | Sim |
| Segredo correto, sem assinatura | `200` | Sim, `unverified` | Não |
| Segredo errado ou corpo alterado | `401` | Não | Não |

Detalhes por gateway: [AbacatePay](/integracao/gateways/abacatepay).

### Resposta

```json
{ "received": true, "status": "stored" }
```

`status`: `stored` (gravado), `duplicate` (o gateway reenviou o mesmo evento) ou `ignored` (evento que não interessa, como saque ou transferência).

## Rotas internas do SaaS

Autenticadas com a chave do app white label (a mesma das demais rotas `/internal`). Servem para o SaaS ler acesso e planos sem falar com o gateway.

### GET /internal/entitlements/:userId

Acessos do usuário nos produtos ligados ao app.

```json
{
  "entitlements": [
    {
      "saas_product_id": "uuid",
      "entitlement_key": "vaygo_pro",
      "status": "active",
      "grants_access": true,
      "is_sandbox": false,
      "valid_until": null,
      "updated_at": "2026-11-11T12:00:00Z"
    }
  ]
}
```

`status`: `active`, `past_due` (cobrança falhou, acesso mantido), `canceled` ou `refunded`. Use `grants_access`.

### GET /internal/plans

Links de checkout por plano, para a tela de assinatura do SaaS.

```json
{
  "plans": [
    { "id": "uuid", "name": "Pro mensal", "checkout_url": "https://...", "entitlement_key": "vaygo_pro", "frequency": "monthly", "price": 49.9 }
  ]
}
```

O preço é informativo: o valor cobrado é o do gateway.
