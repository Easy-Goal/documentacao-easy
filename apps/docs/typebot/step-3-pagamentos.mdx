## Objetivo

Configurar a integração de pagamentos via AbacatePay, definindo precificação, modelo de cobrança e split.

<Note>
**AbacatePay é o único gateway suportado.** Não é possível usar Stripe, PagSeguro ou outros gateways no marketplace EasyGoal.
</Note>

## Split Padrão EasyGoal

| Parte | Percentual |
|-------|-----------|
| Produtor(es) | 80% total |
| EasyGoal | 20% |

Se o produto tiver **co-produtores** (Squad), o split dos 80% é distribuído automaticamente entre owner e co-produtores conforme os percentuais definidos no painel. Nenhuma configuração adicional é necessária neste step.

<Note>
O percentual pode ser negociado conforme o volume de vendas. Use o campo `split_proposal` no step para enviar sua proposta.
</Note>

## Fluxo no Typebot

<Steps>
  <Step title="Conta AbacatePay">
    Verificar se a conta AbacatePay está ativa. Se não, instruir o produtor a criar em [abacatepay.com/register](https://abacatepay.com/register) usando o mesmo email do perfil de produtor.
    → variável `abacatepay_status`
  </Step>
  <Step title="Modelo de Precificação">
    Botões: Assinatura mensal | Assinatura anual | Pagamento único | Freemium + plano pago | Personalizado
    → variável `pricing_model`
  </Step>
  <Step title="Valores">
    - Valor do plano principal (R$) → `main_price`
    - Lista de planos e preços (opcional) → `pricing_details`
  </Step>
  <Step title="Trial / Free Tier">
    Botões: Sim | Não → `has_trial`
    Se sim: quantos dias de trial → `trial_days`
  </Step>
  <Step title="Split de Pagamento">
    Aceita o split padrão 80/20? → `split_accepted`
    Se não: proposta de split → `split_proposal`
  </Step>
  <Step title="Checkout">
    Botões: Checkout EasyGoal | Checkout embeddado | API → `checkout_type`
  </Step>
  <Step title="Webhook de Pagamento">
    URL de webhook para notificação (opcional) → `payment_webhook_url`
  </Step>
</Steps>
