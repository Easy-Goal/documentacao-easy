## Objetivo

Coletar informações fundamentais sobre o produto SaaS que serão exibidas no marketplace EasyGoal.

## Fluxo no Typebot

<Steps>
  <Step title="Boas-vindas">
    Mensagem inicial personalizando pelo nome do produtor usando `{{producer_name}}`.
  </Step>
  <Step title="Nome do Produto">
    Input de texto: "Qual o nome do seu produto/SaaS?" → variável `product_name_input`
  </Step>
  <Step title="Slug">
    Input de texto com validação (apenas letras minúsculas, números e hifens) → variável `slug`
  </Step>
  <Step title="Descrição Curta">
    Input de texto longo: descrição em 1-2 frases para o catálogo → variável `short_description`
  </Step>
  <Step title="Descrição Completa">
    Input de texto longo: funcionalidades e diferenciais → variável `full_description`
  </Step>
  <Step title="Categoria">
    Botões: Gestão | Financeiro | Marketing | RH | Educação | Saúde | Outro → variável `category`
  </Step>
  <Step title="Público-Alvo">
    Input de texto: quem é o usuário ideal → variável `target_audience`
  </Step>
  <Step title="Website">
    Input URL (opcional) → variável `website_url`
  </Step>
  <Step title="Tipo de Integração">
    Botões: **Integrado** (usa SSO EasyGoal) | **Externo** (link externo) → variável `integration_type`
  </Step>
  <Step title="Salvar no Google Sheets">
    Bloco Google Sheets → Insert Row com todas as variáveis mapeadas.
  </Step>
</Steps>

## Validação pelo Admin

- [ ] Nome e slug são únicos e não conflitam com produtos existentes
- [ ] Descrição curta tem menos de 160 caracteres
- [ ] Categoria é adequada para o produto
- [ ] Tipo de integração faz sentido com o que foi descrito
