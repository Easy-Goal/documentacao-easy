## Objetivo

Coletar dados necessários para configurar o tracking de métricas e conversões no Google Analytics 4.

## Fluxo no Typebot

<Steps>
  <Step title="GA4 Existente">
    Botões: Sim | Não | Não sei o que é → `has_ga4`
    Se não tem: a EasyGoal pode criar uma property GA4 para o produto.
  </Step>
  <Step title="Dados do GA4 (se existente)">
    - ID da Property GA4 (ex: G-XXXXXXXXXX) → `ga4_property_id`
    - ID do Measurement Protocol Secret (para eventos server-side, opcional) → `ga4_measurement_secret`
  </Step>
  <Step title="Eventos de Conversão">
    Checkboxes com eventos a rastrear:
    - `sign_up` (Cadastro realizado)
    - `login` (Login via SSO)
    - `begin_trial` (Início de trial)
    - `purchase` (Compra/assinatura)
    - `upgrade` (Upgrade de plano)
    - `feature_used` (Uso de feature chave)

    → variável `conversion_events`

    Outros eventos personalizados (opcional, separados por vírgula) → `custom_events`
  </Step>
  <Step title="UTM Tracking">
    Verifica se o produtor já usa UTMs. Formato padrão EasyGoal:
    `utm_source=easygoal&utm_medium=marketplace&utm_campaign=SEU_PRODUTO`
    → variável `utm_status`
  </Step>
  <Step title="Dashboard de Métricas">
    Botões:
    - Sim, dashboard completo (recomendado)
    - Sim, apenas básico
    - Não, já tenho o meu
    → variável `dashboard_preference`
  </Step>
  <Step title="KPIs Principais">
    Input de texto: "Quais são seus 3 principais KPIs? (Ex: MRR, Churn Rate, CAC)"
    → variável `main_kpis`
  </Step>
</Steps>
