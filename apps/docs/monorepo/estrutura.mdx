## Visão Geral

O ecossistema Easy Goal é composto por repositórios de aplicações independentes e um **monorepo de packages compartilhados** (`easygoal-ui`) que centraliza identidade visual e autenticação.

## Repositórios de Aplicações

```
~/projects/easy/
├── app-front/          Next.js — Marketplace principal (porta 3001)
├── sso/                Next.js — Serviço de autenticação (porta 3000)
├── easy-club-launchpad/  Vite React — Landing page Easy Club
├── lp-easy-club/       Next.js — Landing page Easy Club v2
├── lp-72hrs/           Next.js — Landing page 72hrs
├── site-easygoal/      Next.js — Site institucional
└── documentacao-easygoal/  Mintlify — Esta documentação (porta 3002)
```

```
easygoal-ui/                   github.com/easygoal/easygoal-ui

```

## Paleta de Cores Oficial

Os valores abaixo são a fonte da verdade. Use `@easygoal/ui/tokens` para importar programaticamente.

| Token | HSL | Hex | Uso |
|-------|-----|-----|-----|
| `primary` | `24 95% 53%` | `#F97316` | Botões, links, destaques |
| `primaryLight` | `24 90% 60%` | `#FB923C` | Hover states |
| `primaryDark` | `21 90% 48%` | `#EA580C` | Active states |
| `background` | `222 47% 11%` | `#0F1729` | Fundo principal |
| `card` | `222 47% 13%` | `#121E34` | Cards e painéis |
| `secondary` | `222 47% 18%` | `#182644` | Elementos secundários |
| `mutedForeground` | `215 20% 55%` | `#798BAA` | Texto secundário |

## Adicionando novos packages

Para adicionar um package ao monorepo, crie um novo diretório em `packages/`:

```bash
mkdir -p packages/meu-package/src
```

Crie `packages/meu-package/package.json` com o nome `@easygoal/meu-package`, `tsconfig.json` e `tsup.config.ts` seguindo o padrão dos packages existentes. O pnpm workspace detecta automaticamente.
