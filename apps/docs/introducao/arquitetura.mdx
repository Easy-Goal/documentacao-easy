## Os quatro projetos principais

O ecossistema EasyGoal é composto por quatro projetos principais que trabalham juntos:

<Columns cols={2}>
  <Card title="app-front" icon="browser">
    Marketplace principal. Gerencia produtos SaaS, assinaturas e área do produtor/afiliado/admin.
  </Card>
  <Card title="api-backend" icon="server">
    API centralizada para pagamentos, splits de squad, webhooks de gateway (AbacatePay, Mercado Pago, Kiwify) e integrações externas.
  </Card>
  <Card title="SSO" icon="key">
    Serviço de autenticação centralizado em `sso.easygoal.com.br`. Emite o `eg_session` JWT e recebe o webhook de pagamento.
  </Card>
  <Card title="Club LP" icon="star">
    Landing page de produto que consome o SSO para autenticar usuários e exibir perfil. Pode ser replicado para qualquer produto SaaS.
  </Card>
</Columns>

## Fluxo de pagamento + acesso

```
[Usuário] → [app-front] → paga assinatura
                ↓
        [app-front] ──▶ [api-backend] processa pagamento, calcula splits de squad
                                ↓
        [api-backend / app-front] ──HMAC SHA256──▶ [SSO /api/webhook/payment]
                                              ↓
                                   SSO libera acesso ao usuário
```

### Fluxo de autenticação (Club LP)

```
[Club LP]  →  [SSO]  →  [Club LP callback]  →  [Perfil]
   (1)          (2)              (3)               (4)

1. Botão "Acessar" redireciona para SSO com redirect_to
2. SSO autentica (login com conta EasyGoal) e redireciona de volta
3. Callback recebe ?eg_session=<token>, salva em cookie httpOnly
4. Página de perfil lê cookie, chama SSO /api/me, exibe dados
```

Veja o fluxo completo e correto em [Fluxo OAuth](/sso/fluxo-oauth).

## Exemplo de variáveis de ambiente (app que consome o SSO)

Para um app no padrão do Club LP, que apenas consome o SSO como cliente:

```env
NEXT_PUBLIC_SSO_URL=https://sso-dev.easygoal.com.br
NEXT_PUBLIC_APP_URL=https://app.easygoal.com.br
NEXT_PUBLIC_CLUB_URL=https://club.easygoal.com.br

SECRET_KEY=<gerar-com-node -e "require('crypto').randomBytes(32).toString('hex')">
```

## Resumo dos endpoints SSO

| Método | Endpoint | Quem chama | Descrição |
|--------|----------|-----------|-----------|
| `GET` | `/auth/login?redirect_to=...` | Club LP e demais apps | Inicia autenticação |
| `GET` | `/auth/callback` *(interno)* | SSO após login | Redireciona com `eg_session` |
| `POST` | `/api/webhook/payment` | app-front / api-backend | Notifica pagamento confirmado |
| `GET` | `/api/me` | Club LP | Retorna perfil do usuário logado |
